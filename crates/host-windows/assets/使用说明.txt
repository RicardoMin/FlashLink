FlashLink Windows 主机

1. 在 Windows 10/11 x64 电脑上双击 FlashLink-Windows-x64.exe。首次运行会在当前用户下准备内置引擎。
   使用便携 ZIP 时，请先解压整个压缩包，再运行其中的 FlashLink.exe。
   窗口显示“已就绪，等待手机或平板连接”后，保持主机运行。电脑需要已登录并解锁。
2. 手机或平板连接同一局域网，在 FlashLink 的“我的设备”列表选择这台电脑。
3. 首次配对时，核对手机或平板和 Windows 连接请求中的设备名称、地址和确认码，点击“允许连接”。
   若不是你发起的请求或确认码不一致，请点击“拒绝”。
4. 如果手机或平板上没有找到电脑，点击 Windows 窗口中的“允许专用网络连接”。确认 Windows 提示后，
   请在手机或平板刷新。此功能仅给两个应用添加当前本地子网的专用网络规则。
5. 关闭窗口会收起到托盘。可从“主机”菜单管理授权设备、导出测试报告或退出主机。
6. 普通模式会在物理屏显示桌面。需要隐私时，在电脑端选择“主机 → 安装虚拟屏…”，按系统提示安装。只保留一台已授权设备并用安卓进入桌面后，在主机菜单开启隐私。结束隐私会先锁定 Windows 再恢复本机显示。实体屏实际表现需要在本机确认。

主机启动失败时，窗口会报告阶段和错误。点击“查看日志”可查看引擎诊断。
配置与日志保存在 %LOCALAPPDATA%\FlashLink\DemoHost。
