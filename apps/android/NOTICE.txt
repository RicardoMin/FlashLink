https://github.com/moonlight-stream/moonlight-common-c/tree/8af4562af672dd6b9ed28553ead172984fd9a683

FlashLink modifications, 2026-11-23: use a separate application ID and Flutter launcher,
open the host selected in FlashLink, request encrypted streams, and package the Rust
manager in the Android arm64 build. The FlashLink session shell adds trusted-device
reconnection, in-stream touch controls and aggregate performance measurements. Modified native files retain their upstream license.
2026-11-24: adapt Moonlight's Game touch routing, trackpad button release and
input preference to support switching between direct touch and trackpad during a stream.
2026-11-24: extend Game, the decoder and the connection lifecycle to renegotiate
stream quality and confirm the new settings when the first decoded frame reaches the surface.
2026-11-25: expose audio routing in stream settings and keep the Android audio track
active while its output is muted for computer-only playback.
2026-11-28: add in-session bitrate requests and acknowledgements to the Android
bridge and the pinned moonlight-common-c encrypted control stream.
2026-11-28: add live frame rate control, session-scoped acknowledgements,
renderer pacing updates and seamless display refresh requests on Android.
The integration patches and their build script are under apps/android/.
FlashLink also supports adaptive H.264 resolution changes and confirms the new
dimensions when a decoded output buffer is submitted to the display.
Distributors of the combined APK should provide the complete corresponding source
and build scripts for the exact binary with the distribution.
